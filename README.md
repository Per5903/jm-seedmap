# SeedMap Structures

Аддон для **JourneyMap** и **Xaero's Minimap / World Map** (Fabric, Minecraft 26.2). Показывает на карте структуры, вычисленные по сиду мира, как на сидмапе: деревни, крепости, порталы, храмы, древние города, бастионы, города Края и т.д. Значки появляются и в неразведанной области. Аддон сам находит установленные карты и работает с каждой из них; ни одна из них не обязательна.

## Как это работает

- **Расчёт ванильным кодом самой игры.** Аддон повторяет логику `ChunkGenerator#createStructures`: выбор чанка, частоты, зоны исключения, взвешенный выбор в наборах вроде «крепость/бастион», проверку биома и высоты. Блоки при этом не генерируются. Результат совпадает с тем, что сгенерирует игра (см. «Самотест»).
- **Одиночная игра:** сид и генератор берутся из встроенного сервера автоматически, датапаки мира тоже учитываются.
- **Мультиплеер:** сид вводится вручную и запоминается отдельно для каждого сервера. Генератор собирается из ванильного датапака внутри клиента.
- **Автоопределение измерения.** Аддон берёт измерение, которое сейчас показывает карта JourneyMap. Если в полноэкранной карте переключиться на Незер, будут видны структуры Незера. Переименованные измерения на серверах (например `world_nether`) распознаются по типу измерения.
- Структуры считаются в фоне тайлами 512×512 блоков, начиная от центра экрана. Готовые тайлы кэшируются.

## Чтобы метки не засорялись

- **Структуры — отдельный слой, а не путевые точки.** В списке меток JourneyMap или Xaero их нет. Весь слой включается и выключается клавишей **Y**.
- **Метка по клику.** Правый клик по значку на полноэкранной карте открывает меню:
  - «Поставить метку» превращает структуру в настоящую путевую точку;
  - «Идти сюда» ставит временную метку-цель;
  - «Отметить посещённой»;
  - «Скрыть все такие»;
  - «Копировать координаты».
- **Метки SeedMap живут отдельно.** В JourneyMap это группа «SeedMap», в Xaero — сторонние точки, как у Waystones (видны, когда выбран набор по умолчанию или включено «все наборы»). В твои наборы и файлы точек они не попадают. Хранятся в `config/jm_seedmap/worlds/<мир>.json`. Скрыть все: `/seedmap pins hide`. Удалить все: `/seedmap pins clear`.
- **Ближайшая структура** (клавиша **«.»** или `/seedmap nearest village`). Ищет ближайшую непосещённую структуру выбранного типа в радиусе ~20 000 блоков и ставит метку-цель. Метка исчезает сама, когда подходишь к структуре (радиус настраивается).
- **Посещённые.** Когда подходишь к структуре ближе чем на 48 блоков (по горизонтали), она отмечается посещённой. Дальше её можно показывать как обычно, затемнять (по умолчанию) или скрывать.
- **Экран настроек** (клавиша **«,»**, `/seedmap config` или кнопка в ModMenu): все переключатели выше, сид сервера и типы структур.

## Клавиши (меняются в Управлении → SeedMap)

| Клавиша | Действие |
|---|---|
| Y | показать/скрыть слой структур |
| . | найти ближайшую структуру |
| , | настройки |

## Команды

| Команда | Что делает |
|---|---|
| `/seedmap` | статус: источник сида, состояние для текущего измерения |
| `/seedmap seed <сид>` | задать сид для текущего сервера (число или текст, как при создании мира) |
| `/seedmap clearseed` | забыть сид сервера |
| `/seedmap preset normal\|large_biomes\|amplified` | тип мира сервера (влияет на биомы, а значит и на структуры) |
| `/seedmap on` / `off` | включить/выключить отображение |
| `/seedmap minimap on\|off` | показывать ли значки на миникарте |
| `/seedmap labels on\|off` | подписи под значками (видны при приближении) |
| `/seedmap list` | список структур, клик переключает |
| `/seedmap show <id\|all>` / `hide <id\|all>` | показать/скрыть тип структуры, например `hide minecraft:ruined_portal` |
| `/seedmap nearest <тип>` | ближайшая непосещённая структура типа (village, stronghold, fortress, …) → метка-цель |
| `/seedmap target clear` | убрать метку-цель |
| `/seedmap pins show\|hide\|clear` | показать/скрыть/удалить все метки SeedMap |
| `/seedmap visited mode show\|dim\|hide` | как показывать посещённые |
| `/seedmap visited clear` | сбросить посещённые |
| `/seedmap config` | экран настроек |
| `/seedmap reload` | сбросить кэш |

По умолчанию скрыты шахты, клады и окаменелости Незера: их очень много. Включаются через `/seedmap list`.

Правый клик по значку на полноэкранной карте открывает меню: «Создать метку» (путевая точка JourneyMap) и «Копировать координаты».

Настройки хранятся в `config/jm_seedmap.json`.

## Ограничения

- Расчёт идёт по правилам 26.2. Если сервер на другой версии (например, через ViaFabricPlus), часть структур будет не на своих местах.
- В мультиплеере используется ванильный датапак. Серверные датапаки и моды, меняющие генерацию, не учитываются.
- Сервер должен быть с обычной генерацией. Плагины, подменяющие генератор, ломают точность.

## Сборка

```bash
./gradlew build
```

Готовый jar лежит в `build/libs/jm-seedmap-26.2-1.0.0.jar`. Для работы нужен Fabric API и хотя бы одна карта: JourneyMap или Xaero's Minimap / World Map для 26.2.

JDK 25 Gradle скачает сам через toolchain, если локальной нет. JourneyMap, Xaero's Minimap/World Map и ModMenu подтягиваются с Modrinth Maven только для компиляции и dev-запуска (`./gradlew runClient -Pmaps=jm|xaero|both`), в репозиторий они не входят.

## Самотест

`./gradlew runClient -Pselftest [-Pmaps=jm|xaero|both]` заходит в мир `run/saves/selftest`. Там запускается ванильная стадия `STRUCTURE_STARTS` для области 2048×2048 в Верхнем мире, 1024×1024 в Незере и 3072×3072 в Крае. Самотест сравнивает полученные старты с предсказаниями аддона для обоих путей: «встроенный сервер» и «только сид». Итог пишется в лог строкой `SELFTEST PASS/FAIL`, а в `run/screenshots/` сохраняется скриншот карты. С флагом `-Pmp` клиент подключается к `localhost:25599` и проверяет мультиплеерный сценарий.
