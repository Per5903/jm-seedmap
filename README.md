# SeedMap Structures

Аддон для **JourneyMap** и **Xaero's Minimap / World Map** (Fabric, Minecraft 26.2). Показывает на карте структуры, вычисленные по сиду мира, как на сидмапе: деревни, крепости, порталы, храмы, древние города, бастионы, города Края и т.д. Значки появляются и в неразведанной области. Аддон сам находит установленные карты и работает с каждой из них; ни одна из них не обязательна.

## Как это работает

- **Расчёт ванильным кодом самой игры.** Аддон повторяет логику `ChunkGenerator#createStructures`: выбор чанка, частоты, зоны исключения, взвешенный выбор в наборах вроде «крепость/бастион», проверку биома и высоты. Блоки при этом не генерируются. Результат совпадает с тем, что сгенерирует игра (см. «Самотест»).
- **Одиночная игра:** сид и генератор берутся из встроенного сервера автоматически, датапаки мира тоже учитываются.
- **Мультиплеер:** сид вводится вручную, подбирается по хешу сервера или берётся из SeedCrackerX и запоминается отдельно для каждого сервера. Генератор собирается из ванильного датапака внутри клиента, плюс датапаки сервера, если положить их в папку (см. ниже).
- **Автоопределение измерения.** Аддон берёт измерение, которое сейчас показывает карта JourneyMap. Если в полноэкранной карте переключиться на Незер, будут видны структуры Незера. Переименованные измерения на серверах (например `world_nether`) распознаются по типу измерения.
- Структуры считаются в фоне тайлами 512×512 блоков, начиная от центра экрана. Готовые тайлы хранятся в памяти и на диске (`jm_seedmap/cache/`, до 64 МБ): при повторном входе в тот же мир карта заполняется сразу, без пересчёта.

## Чтобы метки не засорялись

- **Структуры — отдельный слой, а не путевые точки.** В списке меток JourneyMap или Xaero их нет. Весь слой включается и выключается клавишей **Y**.
- **Метка по клику.** Правый клик по значку на полноэкранной карте открывает меню:
  - «Поставить метку» превращает структуру в настоящую путевую точку;
  - «Идти сюда» ставит временную метку-цель;
  - «Отметить посещённой»;
  - «Скрыть все такие»;
  - «Копировать координаты».
- **Метки SeedMap живут отдельно.** В JourneyMap это группа «SeedMap», в Xaero — сторонние точки, как у Waystones (видны, когда выбран набор по умолчанию или включено «все наборы»). В твои наборы и файлы точек они не попадают. Хранятся в `config/jm_seedmap/worlds/<мир>.json`. Скрыть все: `/seedmap pins hide`. Удалить все: `/seedmap pins clear`.
- **Ближайшая структура** (клавиша **«.»** или `/seedmap nearest village`). Ищет ближайшую непосещённую структуру выбранного типа в радиусе ~20 000 блоков и ставит метку-цель. Метка исчезает сама, когда подходишь к структуре (радиус настраивается).
- **Посещённые.** Когда подходишь к структуре ближе чем на 48 блоков по горизонтали и не дальше 32 блоков по высоте, она отмечается посещённой. Пройти над древним городом, шахтой или комнатами испытаний не считается, нужно спуститься к ним. Оба расстояния настраиваются. Посещённые можно показывать как обычно, затемнять (по умолчанию) или скрывать. Метка-цель на подземной структуре тоже снимается, только когда спустишься к ней.
- **Список меток** (`/seedmap pins` или кнопка на вкладке «Метки»): все метки SeedMap с расстоянием и направлением. Нажми на метку, чтобы переименовать её, сделать целью, скопировать координаты или удалить.
- **Экран настроек** (клавиша **«,»**, `/seedmap config` или кнопка в ModMenu), вкладки:
  - «Карта» — слои (структуры, слайм-чанки, биомы), посещённые, производительность и кэш;
  - «Структуры» — с иконками и кнопками «Показать все» / «Скрыть все», чтобы оставить только один тип;
  - «Метки» — список меток, радиусы;
  - «Сид» — ввод, тип мира, SeedCrackerX, датапаки сервера, проверка и подбор.

## Проверка и подбор сида

При входе сервер присылает клиенту **хеш сида** (SHA-256, по нему игра сглаживает биомы).

- **Проверка** запускается кнопкой «Проверить сейчас» на вкладке «Сид» или командой `/seedmap check`. Хеш даёт точный ответ «верный / неверный». Если сервер хеш подменяет, проверка дополнительно сравнивает настоящие биомы загруженных чанков с предсказанными. Автопроверка выключена по умолчанию и включается там же. После ввода сида проверка запускается один раз сама.
- **Подбор сида** — кнопка «Подобрать сид» или `/seedmap find`. Перебираются все сиды, заданные текстом или числом в пределах ±2 млрд (2³² вариантов): в фоне, на всех ядрах, максимум около 4 минут, небольшие числа находятся мгновенно. Найденный сид сохраняется для сервера.
- **Случайный 64-битный сид** так не найти. Для него есть SeedCrackerX (см. ниже).
- Если сервер скрывает хеш, подбор недоступен, а проверка работает только по биомам.

## Несколько миров на одном сервере

На серверах с лобби, выживанием и ресурсным миром за одним адресом у каждого мира свой сид. Для этого есть профили сида: у каждого профиля свой сид, тип мира, папка датапаков, метки и посещённые.

- Мир узнаётся сам по хешу сида, который сервер присылает при входе в мир. Профиль запоминает хеши миров, в которых он был выбран, и профиль, чей сид даёт этот хеш, тоже подходит.
- Если попал в мир, которого не знает ни один профиль, в чате появится выбор: существующие профили или «[+ новый]».
- Выбрать вручную: переключатель «Профиль» на вкладке «Сид» или `/seedmap profile use <имя>`. Список: `/seedmap profile`. Создать или удалить: `/seedmap profile new [имя]`, `/seedmap profile delete <имя>`.
- Если на сервере один мир, ничего делать не нужно: работает профиль `default`, как раньше.

## SeedCrackerX

Если установлен [SeedCrackerX](https://github.com/19MisterX98/SeedcrackerX), аддон работает с ним сам:
- найденный им сид сразу сохраняется для сервера, и карта пересчитывается;
- если он нашёл только «структурный сид» (младшие 48 бит), аддон достраивает полный сид по хешу сервера за долю секунды.

Отключается переключателем «Сид из SeedCrackerX» на вкладке «Сид». Вручную: `/seedmap find structure <число>`.

## Датапаки сервера

Если сервер играет с датапаками генерации (Terralith, свои структуры, изменённая частота деревень, другой тип мира через `dimension/overworld.json`), положи их копии в папку сервера:

```
config/jm_seedmap/datapacks/<адрес_сервера>/
```

Кнопка «Открыть папку» на вкладке «Сид» или `/seedmap datapacks` создаёт и открывает её. Подходят zip-архивы и распакованные папки, как в `datapacks` мира. После копирования нажми «Перечитать». Строка под кнопками показывает, какие датапаки загружены, или ошибку загрузки. Моды, меняющие генерацию кодом, так учесть нельзя.

## Слой биомов

Раскраска карты по биомам из сида, как на chunkbase. Включается на вкладке «Карта» или `/seedmap biomes on`.
- **Xaero's World Map:** по умолчанию раскрашивается только то, что ещё не разведано (участки 64×64 блока, которых нет на карте Xaero). Под курсором подписано название биома.
- **JourneyMap:** API не сообщает, что разведано, поэтому слой полупрозрачный поверх всей полноэкранной карты.
- Непрозрачность настраивается (по умолчанию 60%). Биом берётся для поверхности: подземные биомы (пещеры, глубокая тьма) не рисуются. С настоящими биомами поверхности слой совпадает примерно в 98% мест (см. «Самотест»).
- **Подсветка, как на seedmap.** Вкладка «Биомы» в поиске: у каждого биома есть кнопка «Подсветить», сверху строка поиска по названию. Подсвеченные биомы рисуются ярко поверх всей карты, в том числе разведанной, остальные затемняются. Можно подсветить несколько. «Сбросить подсветку» убирает всё. Командой: `/seedmap biomes highlight minecraft:cherry_grove`, `/seedmap biomes clear`.
- Посчитанные биомы тоже хранятся в кэше на диске (`jm_seedmap/cache/biomes`), повторно открытая карта раскрашивается сразу.

## Структуры рядом

**Список.** Вкладка «Рядом» в поиске, кнопка на вкладке «Метки» или `/seedmap nearby`. Выбираешь тип (по умолчанию «все, что на карте») и радиус до 5000 блоков. В каждой строке:
- значок;
- название;
- расстояние и направление;
- галочка, если структура уже посещена.

Наведи курсор, чтобы увидеть подробности, или нажми, чтобы открыть экран структуры.

**На экране без карты (HUD).** Включается на вкладке «Карта» («Структуры рядом на экране»), командой `/seedmap hud` или клавишей. Клавиша по умолчанию не назначена, её можно задать в Управлении → SeedMap. Показывает ближайшие структуры тех типов, что включены на карте:
- значок типа;
- название;
- расстояние;
- стрелку, которая поворачивается вместе с тобой.

Сверху всегда стоит текущая цель. Место на экране, число строк и радиус настраиваются.

## Режим фарма

Для обхода структур одного типа подряд: деревня за деревней, портал за порталом.
- На вкладке «Структуры» в поиске переключи «Режим» на «фарм ×1», «×3» или «×5» и выбери тип. Или командой `/seedmap farm village 3`.
- Метки ставятся на N ближайших непосещённых структур этого типа, ближайшая становится целью (её видно в HUD со стрелкой).
- Когда доходишь до цели, структура отмечается посещённой, а метки сами переезжают на следующие ближайшие такого же типа. В строке над хотбаром пишется, куда идти дальше.
- Остановить: кнопка «Стоп» там же или `/seedmap farm stop`. Метки фарма при этом убираются, твои собственные остаются.

## Подробности о структуре

«Подробности…» в меню правого клика на карте (Xaero и JourneyMap) или клик в списке «Рядом». Аддон собирает все части структуры так же, как игра, но блоки не ставит, и смотрит, что в них:

| Структура | Что видно |
|---|---|
| все | размер, сундуки и бочки, спавнеры |
| деревня | дома и кровати, оружейник/инструментальщик/бронник/храм/библиотека/картограф, деревня зомби |
| бастион | тип: сокровищница, мост, конюшня хоглинов или жилой; золотые блоки |
| древний город, особняк | размер и число частей |
| крепость (Энд-портал) | библиотеки (и сколько двухэтажных), координаты комнаты с порталом, кнопка «цель: комната с порталом» |
| крепость Незера | спавнеры ифритов, комнаты с адским наростом |
| комнаты испытаний | хранилища и зловещие хранилища, спавнеры испытаний |
| разрушенный портал | где стоит (на поверхности, в земле, в горе, под водой), сколько будет обсидиана и плачущего обсидиана, хватит ли на рамку |
| иглу | есть ли подвал |
| подводные руины | большие или маленькие |

Обсидиан разрушенного портала считается почти точно. Игра превращает часть обсидиана в плачущий по случайному числу, которое зависит только от координат блока, и аддон делает то же самое. Изредка незерак, которым игра потом обкладывает портал, съедает 1–2 блока у основания. Самотест сверяет эти числа, хранилища комнат испытаний и кровати деревень с тем, что сервер реально сгенерировал.

## Поиск структур и биомов

Клавиша **«.»** или `/seedmap search` открывает экран поиска с вкладками «Структуры» и «Биомы» и строкой фильтра. Выбранное становится меткой-целью:
- для структуры — ближайшая непосещённая;
- для биома — ближайший в радиусе 6400 блоков, как `/locate biome`.

Командой: `/seedmap nearest biome minecraft:mushroom_fields`.

## Города Края с кораблём

У каждого города Края аддон собирает все части так же, как это делает игра, поэтому знает, у какого города есть корабль с элитрами. Такие города отмечены значком элитр и выделены в отдельный тип: их можно показывать без обычных городов и искать ближайший через `/seedmap nearest end_city_ship`.

## Слайм-чанки

Зелёная сетка на карте (полноэкранная JourneyMap, карта мира и миникарта Xaero, только Верхний мир). На миникарте Xaero сетка поворачивается вместе с картой. Включается командой `/seedmap slime on` или в настройках. `/seedmap slime here` показывает, слаймовый ли чанк под тобой.

## Производительность

Настройка «Нагрузка» на вкладке «Карта» (`/seedmap perf auto|low|normal|high`):

| Режим | Потоки | Радиус расчёта | Меток на карте мира | Клетка биомов |
|---|---|---|---|---|
| Низкая | 1 | 6 тайлов (~3 000 блоков) | 400 | 16 блоков |
| Обычная | половина ядер, до 3 | 10 тайлов | 1 200 | 8 блоков |
| Высокая | ядра − 2, до 6 | 14 тайлов | 3 000 | 4 блока |

«Авто» выбирает «Низкую» на компьютерах с 4 ядрами и меньше или когда игре выделено меньше 3 ГБ памяти, иначе «Обычную». Потоки работают с пониженным приоритетом, список меток пересчитывается только когда карта сдвинулась или появились новые данные, а не каждый кадр.

## Совместимость

- Проверено вместе с ModernFix, C2ME, Lithium, ScalableLux и ViaFabricPlus (`./gradlew runClient -Pselftest -Pextra=...`).
- Если новая версия Xaero или JourneyMap изменит то, на что опирается аддон, отключится только этот слой с одной строкой в логе, игра и остальные карты продолжат работать.
- При заходе через ViaFabricPlus на сервер другой версии или на сервер, который в статусе сообщает другую версию (например, Paper 1.21 с ViaVersion), в чат выводится предупреждение: генерация там отличается, и часть структур будет не на месте.

## Клавиши (меняются в Управлении → SeedMap)

| Клавиша | Действие |
|---|---|
| Y | показать/скрыть слой структур |
| . | поиск структур и биомов |
| , | настройки |
| не назначена | структуры рядом на экране (HUD) |
| не назначена | список «Структуры рядом» |

## Команды

| Команда | Что делает |
|---|---|
| `/seedmap` | статус: источник сида, состояние для текущего измерения |
| `/seedmap seed <сид>` | задать сид для текущего сервера (число или текст, как при создании мира) |
| `/seedmap clearseed` | забыть сид сервера |
| `/seedmap preset normal\|large_biomes\|amplified` | тип мира сервера (влияет на биомы, а значит и на структуры) |
| `/seedmap on` / `off` | включить/выключить отображение |
| `/seedmap minimap on\|off` | показывать ли значки на миникарте |
| `/seedmap labels on\|off` | подписи под значками (видны при приближении) |
| `/seedmap list` | список структур, клик переключает |
| `/seedmap show <id\|all>` / `hide <id\|all>` | показать/скрыть тип структуры, например `hide minecraft:ruined_portal` |
| `/seedmap nearest <тип>` | ближайшая непосещённая структура типа (village, stronghold, fortress, …) → метка-цель |
| `/seedmap target clear` | убрать метку-цель |
| `/seedmap pins` | список меток |
| `/seedmap pins show\|hide\|clear` | показать/скрыть/удалить все метки SeedMap |
| `/seedmap visited mode show\|dim\|hide` | как показывать посещённые |
| `/seedmap visited clear` | сбросить посещённые |
| `/seedmap config` | экран настроек |
| `/seedmap check` | проверить сид (хеш сервера + биомы) |
| `/seedmap find` / `find structure <n>` / `find stop` / `find status` | подбор сида по хешу сервера |
| `/seedmap search` | экран поиска структур и биомов |
| `/seedmap nearest biome <id>` | ближайший биом → метка-цель |
| `/seedmap slime on\|off\|here` | сетка слайм-чанков / слаймовый ли этот чанк |
| `/seedmap nearby` | список структур рядом |
| `/seedmap farm <тип> [сколько]` / `farm stop` | режим фарма: метки на ближайших непосещённых, переезжают по мере обхода |
| `/seedmap biomes highlight <id>` / `biomes clear` | подсветить биом на карте / снять подсветку |
| `/seedmap hud` / `hud on\|off` | структуры рядом на экране |
| `/seedmap profile` / `profile use\|new\|delete <имя>` | профили сида для серверов с несколькими мирами |
| `/seedmap biomes on\|off` | слой биомов |
| `/seedmap datapacks` | открыть папку датапаков сервера и показать, что загружено |
| `/seedmap perf auto\|low\|normal\|high` | нагрузка на компьютер |
| `/seedmap cache clear` | удалить кэш структур на диске |
| `/seedmap reload` | пересчитать всё (и перечитать датапаки сервера) |

По умолчанию скрыты шахты, клады и окаменелости Незера: их очень много. Включаются через `/seedmap list`.

Правый клик по значку на полноэкранной карте открывает меню: «Создать метку» (путевая точка JourneyMap) и «Копировать координаты».

Настройки хранятся в `config/jm_seedmap.json`.

## Ограничения

- Расчёт идёт по правилам 26.2. Если сервер на другой версии, часть структур будет не на своих местах (аддон предупреждает об этом).
- В мультиплеере датапаки сервера учитываются, только если положить их в папку сервера. Моды и плагины, меняющие генерацию кодом, ломают точность.
- В JourneyMap слой биомов рисуется поверх всей карты: разведанное от неразведанного там не отличить.

## Планы

Что стоит добавить и известные ограничения — в [ROADMAP.md](ROADMAP.md).

## Сборка

```bash
./gradlew build
```

Готовый jar лежит в `build/libs/jm-seedmap-26.2-<версия>.jar`. Для работы нужен Fabric API и хотя бы одна карта: JourneyMap или Xaero's Minimap / World Map для 26.2.

JDK 25 Gradle скачает сам через toolchain, если локальной нет. JourneyMap, Xaero's Minimap/World Map и ModMenu подтягиваются с Modrinth Maven только для компиляции и dev-запуска (`./gradlew runClient -Pmaps=jm|xaero|both`), в репозиторий они не входят.

## Самотест

`./gradlew runClient -Pselftest [-Pmaps=jm|xaero|both]` заходит в мир `run/saves/selftest`. Там запускается ванильная стадия `STRUCTURE_STARTS` для области 2048×2048 в Верхнем мире, 1024×1024 в Незере и 3072×3072 в Крае. Самотест сравнивает полученные старты с предсказаниями аддона для обоих путей: «встроенный сервер» и «только сид». Ещё он сверяет слой биомов с биомом на реальной высоте поверхности, проверяет кэш на диске (сброс и чтение обратно) и разбор версии сервера. Итог пишется в лог строкой `SELFTEST PASS/FAIL`, а в `run/screenshots/` сохраняются скриншоты карт и экранов.

- `-Pworld=selftest-dp` — мир с тестовыми датапаками из `testdata/datapacks` (деревни каждые 12 чанков, Верхний мир с большими биомами, своя структура в zip). Путь «только сид» получает те же датапаки, как игрок, скопировавший их с сервера.
- `-Pmp` — клиент подключается к `localhost:25599` и проверяет мультиплеер: подбор сида по хешу, проверку сида и, если установлен SeedCrackerX (`-Pextra=seedcracker`, jar в `libs/`), передачу сида через его API.
- `-Pextra=modernfix,c2me,lithium,...` — добавить моды для проверки совместимости.
