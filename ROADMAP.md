# Что добавить в SeedMap Structures

Сборник идей и известных ограничений. Сверху — то, что даст больше всего пользы.

## Высокий приоритет

- [ ] **Датапаки сервера в мультиплеере.** Если сервер играет с Terralith, Tectonic или своими структурами, расчёт по ванильным данным врёт. Решение: папка `config/jm_seedmap/datapacks/<сервер>/`. Положил туда zip датапака, и аддон грузит его поверх ванильного так же, как игра при создании мира. Работает только для датапаков: моды, меняющие генерацию кодом, так не поддержать.
- [ ] **Интеграция с SeedCrackerX.** Брать найденный им сид сразу, а если он нашёл только «структурный сид» (48 бит), автоматически достраивать полный по хешу сервера. Сейчас это делается руками через `/seedmap find structure <число>`.
- [ ] **Предупреждение о другой версии сервера.** При заходе через ViaFabricPlus на сервер 1.21.x генерация отличается от 26.2, и часть структур окажется не на месте. Нужно определять целевую версию и показывать явное предупреждение (проверка сида это частично ловит, но без объяснения причины).
- [ ] **Слайм-чанки на миникарте Xaero.** Сейчас их нет: миникарта вращается вместе с игроком, заливку чанков надо рисовать с учётом поворота.
- [ ] **Список меток.** Экран со всеми метками SeedMap: удалить одну, переименовать, сделать целью, показать расстояние. Сейчас метку можно убрать только через меню на карте или все сразу.

## Средний приоритет

- [ ] **Список «все структуры рядом».** Таблица структур выбранного типа в радиусе N блоков: расстояние, направление, посещена или нет, кнопка «сделать целью». Удобно, когда нужна не ближайшая, а лучшая из нескольких.
- [ ] **Карта биомов на неразведанной области.** Раскраска ещё не открытых участков по биомам, как на chunkbase. Тяжело для производительности, поэтому как отдельный слой и только при приближении.
- [ ] **Стрелка до цели на экране.** Небольшой компас с расстоянием до метки-цели, без открытия карты. Полезно, если миникарта выключена.
- [ ] **«Открыть на chunkbase».** Пункт в меню правого клика: открыть chunkbase в браузере с тем же сидом, измерением и координатами.
- [ ] **Подробности о структуре.** Тип деревни уже понятен по имени. Можно добавить: размер древнего города, есть ли у разрушенного портала подходящий для починки размер, количество сундуков в комнатах испытаний.
- [ ] **Несколько миров на одном сервере.** Серверы с несколькими мирами на одном адресе (лобби, выживание, ресурсный мир) сейчас делят один сид. Нужны профили сида на измерение или на мир.
- [ ] **Кэш на диск.** Посчитанные тайлы сохранять по сиду, чтобы после перезахода карта заполнялась мгновенно.

## Низкий приоритет

- [ ] **Другие версии и загрузчики.** Порты на 26.1, 26.3 и NeoForge.
- [ ] **Публикация на Modrinth / CurseForge** со страницей мода и скриншотами.
- [ ] **CI на GitHub Actions.** Сборка jar на каждый коммит и запуск самотеста точности без окна (headless) с публикацией jar в релиз.
- [ ] **Переводы** на другие языки (сейчас русский и английский).

## Известные ограничения

- Расчёт по правилам 26.2. Сервер другой версии даст неточные структуры.
- В мультиплеере не учитываются серверные датапаки и моды генерации (см. первый пункт выше).
- Случайный 64-битный сид нельзя подобрать по хешу: перебор 2⁶⁴ невозможен. Подбор работает только для текстовых и «коротких» числовых сидов или со структурным сидом от SeedCrackerX.
- Если сервер скрывает хеш сида, подбор недоступен, а проверка работает только по биомам.
- Посещение считается по горизонтали: подземная структура (древний город, комнаты испытаний) отмечается, даже если просто пройти над ней.
- На миникарте Xaero нет слайм-чанков.
- Совместимость с модами-оптимизаторами генерации проверена только для ModernFix (с 1.2.1). Похожие моды могут ломать расчёт так же.
